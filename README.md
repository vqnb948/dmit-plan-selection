## 同一个洛杉矶，为什么卖出三种价

答案在回程路由上。美国机房到中国大陆的物理距离摆在那里，线路质量决定晚高峰会不会卡，而优质线路的带宽成本比公共互联高出好几倍。

三条主力线路的分工大致是这样：CN2 GIA（AS4809）是中国电信的精品国际出口，负载低、晚高峰稳，代价是贵，而且只对电信方向有效；AS9929 是中国联通的工业互联网骨干，联通回程质量好，带宽通常给得比 CN2 GIA 宽松；CMIN2（AS58807）是移动方向的精品回程。不走这三条的，就是各家的普通国际线路，也就是 DMIT 命名里的 Tier 1，便宜、带宽给得大，晚高峰容易抖。

延迟上有个可以自己核验的基准：西海岸优化线路 150–180ms 属于优秀，西海岸普通线路 190–230ms 属正常范围，超过 250ms 基本可以判断绕路了。这是第三方测评长期测出来的经验值，不是 DMIT 官方数据。你在下单前可以用测试 IP 跑一遍 ping 和 traceroute 对照，比对商家的宣传语可靠。

DMIT 三档的定价逻辑，看同价位给多少流量最直观：

| --- | --- | --- | --- |
| Pocket SSD | Premium | 1.5TB | 4Gbps |
| Pocket SSD | Eyeball | 3TB | 4Gbps |
| 每月 $34.9 | 线路 | 月流量 | 带宽 |
| --- | --- | --- | --- |
| STARTER SSD | Premium | 3TB | 10Gbps |
| STARTER SSD | Eyeball | 5TB | 10Gbps |

同样的钱，Eyeball 给的流量是 Premium 的两倍左右。Tier 1 更极端：$12.9/月就能拿 4TB，$21.9/月拿 8TB。线路越贵，同等价格能买到的流量越少，这就是三档价差的全部来源。

具体每一档对应哪条骨干网，官网各套餐页面的线路标注才是准的。买之前想确认某档是不是 CN2 GIA 或 CMIN2，看套餐页的 AS 号标注，或者直接开工单问一句，比看任何测评都可靠。

## 只写在退款条款里的六条限制

DMIT 官方文档给的退款政策比多数商家宽松：3 天内全额退，30 天内按剩余价值退，不需要理由。但“不需要理由”后面跟了一串条件，这些条件才是决定你能不能拿回钱的部分。

**3 天全额退款有流量门槛。** 购买不超过 3 天，并且虚拟机上的传输量不超过 30GB，两个条件同时满足才算全额。跑完一次大文件传输就可能超标，测试期间别拿它下东西。

**30 天部分退款按两种算法取高者。** 退款金额按实际支付金额算，如果从已使用流量折算出的价值更高，就按剩余流量退，否则按剩余服务时间退。说白了，用得越少退得越多。

**四种情况明确不退。** 遭受 DDoS 攻击、以网络状况不佳为由、以 IP 地理位置为由、以及 IP 在某些区域不可用但流量已超过 3GB。第三条尤其要注意：如果你的 IP 在国内某地被墙，而你已经跑了 3GB 以上流量，退款申请会被拒。官方给的补救是“发现 IP 全球范围不可访问时，在购买当天第一时间联系销售部门”，这个时间窗口很短。

**同一系列最多退 3 次。** 按自然人计算，同一产品系列退满 3 次之后不再受理，系统识别到多账户关联且累计超过 3 次同样拒退。

**退到哪里影响你实际拿到多少。** 退到 DMIT 账户余额不收手续费；退回原支付方式要扣支付网关收的费用，其中支付宝在退款时会返还手续费，所以走支付宝退回不收费。处理时效通常 48 小时内，高峰期会延迟。

**退款后数据直接删除。** 发起退款时实例会被停机以防止继续消耗流量，确认退款后实例删除、数据不可恢复。要留数据，先备份再申请。

这六条拼起来，试用成本可以压到很低：充一笔钱开一台 TINY，三天内测完延迟和实际速度，不满意走全额退款，损失接近零。前提是别超 30GB 流量，别拿它扛攻击，也别等到第四天才想起来。

## 常见问题

**美国云服务器需要备案吗？**

不需要。备案针对的是中国大陆境内的服务器，美国机房不涉及。

**洛杉矶机房延迟多少算正常？**

西海岸优化线路 150–180ms 是优秀水平，普通线路 190–230ms 属正常，超过 250ms 大概率绕路。选机房优先西海岸的洛杉矶、圣何塞、西雅图，比东海岸低 50ms 以上。

**流量用超了会怎样？**

DMIT 的公开文档里没有针对超额流量的统一说明，各套餐页面标注的是月流量额度。买之前如果流量对你关键，在结算页或工单里确认超额后的处理方式（限速、停机还是按量计费），别默认。

**能不能退？**

3 天内、流量不超 30GB，全额退；30 天内按剩余价值退。DDoS、网络不佳、IP 地理位置、IP 部分地区不可用且流量已超 3GB，这四种不退。同系列每人最多退 3 次。

**IP 被封了怎么办？**

先看时间。购买当天发现 IP 全球范围不可访问，立刻联系销售部门，这是官方给的处理窗口。超过 3GB 流量之后再以 IP 不可用为由申请退款，会被拒绝。

**支持支付宝吗？**

支持。官方退款文档里明确写了支付宝退款不收取手续费，说明它是可用支付方式之一。其他支付渠道以结算页显示为准。
